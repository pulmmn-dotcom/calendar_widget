# 교대캘린더 위젯 앱 설계

작성일: 2026-09-24
상태: 사용자 승인 완료 (브레인스토밍 단계)

## 1. 목적

교대 근무자가 자신의 근무 패턴을 등록하면, 안드로이드 홈화면 위젯으로 근무 일정을 한눈에 볼 수 있게 하는 개인용 앱. 인터넷 연결 없이 완전히 오프라인으로 동작하며, 모든 데이터는 휴대폰 안에만 저장한다. 여러 기기 동기화, 클라우드 백업, 계정 로그인은 이번 범위에 포함하지 않는다.

## 2. 전체 구성

- **위젯 4종**
  - 한달위젯 (4x4): 한 달 전체(최대 6주) 표시
  - 작은한달위젯 (3x2): 한 달 전체를 더 작게, 숫자와 밑줄 색만 표시
  - 일주일위젯 (4x1): 이번 주 7일을 가로로, 근무 이름과 짧은 메모 표시
  - 하루위젯 (1x1): 오늘 하루만 크게 표시
- **본 앱 (아이콘으로 여는 메인 화면)**
  - 달력 보기/편집
  - 근무 종류 관리
  - 근무 패턴 관리
  - 위젯 추가 안내
- 같은 종류의 위젯을 홈화면에 여러 개 놓을 수 있고, 각 위젯의 디자인 설정(투명도, 배경색, 글자 크기, 음력 표시 여부)은 위젯마다 독립적으로 저장한다.

## 3. 데이터 모델

### 3.1 근무 종류 (ShiftType)
- id
- 이름 (자유 텍스트, 예: 주간, 야간, 비번, 휴무)
- 색상 (사용자가 색상 팔레트에서 선택)
- 개수 제한 없음

### 3.2 근무 패턴 (ShiftPattern)
- id
- 이름 (선택, 관리용)
- 근무 종류를 순서대로 나열한 목록 (길이 제한 없음, 자유 입력)
- 시작 날짜
- 시작 날짜부터 이 순서가 무한 반복되며 달력에 자동으로 채워짐
- 여러 패턴을 만들 수 있고, 특정 시점부터 다른 패턴으로 전환 가능 (전환 시점 이후 날짜는 새 패턴 기준으로 다시 계산)

### 3.3 날짜별 오버라이드 (DayOverride)
- 날짜
- 근무 종류 (패턴이 자동으로 정한 값을 덮어씀)
- 패턴이 바뀌어도 오버라이드가 있는 날짜는 오버라이드 값이 우선

### 3.4 메모 (Memo)
- 날짜
- 텍스트 (자유 길이, 표시는 위젯 공간에 따라 잘림)
- 본 앱과 위젯(탭해서 입력창 호출) 양쪽에서 작성/수정 가능

### 3.5 음력
- 별도 저장 없이 날짜로부터 오프라인 변환 알고리즘으로 즉시 계산 (인터넷 불필요)

### 3.6 위젯 인스턴스 설정 (WidgetSettings)
- 위젯 인스턴스 id (안드로이드가 위젯마다 부여하는 고유 id 기준)
- 위젯 종류 (4종 중 하나)
- 배경 투명도 (0~100%)
- 배경색
- 날짜/요일 글자 크기
- 근무 이름 글자 크기
- 메모 글자 크기 (일주일/하루위젯에서 사용)
- 음력 표시 여부 (일주일/하루위젯에서만 실제로 보임)
- 주 시작 요일 (기본 일요일, 설정에서 월요일로 변경 가능)

## 4. 위젯별 화면 사양

### 4.1 한달위젯 (4x4)
- 상단: 연/월 표시, 이전/다음 달 이동 버튼
- 요일 행: 일요일 빨강, 토요일 파랑, 평일 회색
- 날짜 칸: 배경은 위젯 배경색 그대로, 칸 아래쪽에 근무 색상으로 얇은 밑줄, 날짜 숫자 아래 작은 글씨로 근무 이름
- 메모 있는 날: 칸 우측 상단에 작은 노란 점
- 오늘 날짜: 칸에 강조 테두리
- 이전/다음 달의 날짜(앞뒤 채움용)는 흐린 회색, 근무 정보 없음
- 음력 표시 없음 (공간 부족)

### 4.2 작은한달위젯 (3x2)
- 한달위젯과 같은 달력 구조지만 근무 이름 텍스트는 생략, 밑줄 색상만 표시
- 요일/오늘 강조/메모 점은 동일하게 유지
- 음력 표시 없음 (공간 부족)

### 4.3 일주일위젯 (4x1)
- 이번 주(주 시작 요일 설정 기준) 7일을 가로로 배치
- 각 칸: 요일, 날짜, 근무 이름, 밑줄 색상, 짧은 메모 텍스트(1~2글자 정도로 잘림)
- 음력 표시를 켜면 날짜 아래 작게 음력 날짜 추가
- 오늘 칸은 테두리로 강조

### 4.4 하루위젯 (1x1)
- 날짜, 요일, 근무 이름(크게), 메모(있으면 아래 작게)
- 음력 표시를 켜면 맨 아래 작게 표시
- 탭하면 메모 입력창 호출

## 5. 본 앱 화면 사양

1. **홈(달력) 화면**: 월간 달력 뷰, 날짜 탭 시 그 날의 근무 종류 변경(오버라이드 저장) + 메모 입력 가능한 하단 시트, 상단에 이전/다음 달 이동
2. **근무 종류 관리 화면**: 목록 형태로 추가/수정/삭제, 이름과 색상 입력
3. **근무 패턴 관리 화면**: 근무 종류를 순서대로 배치해서 패턴 생성, 시작일 지정, 기존 패턴 목록 확인/수정/삭제
4. **위젯 추가 안내 화면**: 안드로이드 특성상 위젯 추가는 홈화면에서 직접 해야 하므로, 각 위젯 종류별 간단한 설명과 미리보기만 제공

## 6. 위젯 디자인 설정 흐름

- 위젯을 홈화면에 새로 추가하면 안드로이드가 자동으로 설정 화면(구성 액티비티)을 띄움
- 이 화면에서 배경 투명도, 배경색, 글자 크기들, 음력 표시 여부를 미리보기와 함께 조절 후 "완료"를 누르면 위젯이 홈화면에 배치됨
- 이미 배치된 위젯도 같은 설정 화면을 다시 열어 수정 가능 (앱 아이콘 없이 위젯을 길게 눌러 진입)

## 7. 기술 구현 방향

- 언어: Kotlin
- 위젯 구현: Jetpack Glance (구글의 최신 위젯 프레임워크)
- 본 앱 UI: Jetpack Compose
- 저장소: Room (SQLite 기반 로컬 데이터베이스), 앱 내부 저장공간 사용
- 음력 변환: 오프라인 변환 알고리즘 라이브러리 사용 (외부 API/인터넷 불필요)
- 최소 지원 버전: Android 8.0 (API 26) 이상
- 위젯 자정 갱신: AlarmManager 기반으로 매일 00:00 근처에 모든 위젯 갱신 예약
- 데이터 변경 시(근무 패턴/오버라이드/메모/설정) 관련된 모든 위젯 즉시 갱신

## 8. 예외 상황 처리

- 근무 패턴이 하나도 없을 때: 위젯에 "근무 패턴을 등록해주세요" 안내 문구 표시, 탭하면 본 앱의 근무 패턴 관리 화면으로 이동
- 위젯 크기가 최소 크기보다 작게 배치된 경우: 텍스트 크기를 자동으로 한 단계 축소해서 겹침 방지
- 메모/설정 입력 중 다른 화면으로 전환되거나 앱이 종료되어도 입력값은 바로 저장 (임시 저장 버튼 없이 즉시 반영)
- 근무 종류가 삭제되었는데 과거 날짜에 그 근무 종류가 남아있는 경우: 해당 날짜는 "삭제된 근무"로 표시하고 회색으로 처리 (데이터는 보존, 근무 종류 목록에서만 사라짐)

## 9. 테스트 방침

- 근무 패턴 반복 계산 로직(패턴 전환, 오버라이드 우선순위)에 대한 단위 테스트
- 음력 변환 로직에 대한 단위 테스트 (알려진 날짜 몇 개로 검증)
- 각 위젯 크기별 레이아웃을 실제 에뮬레이터/기기에서 육안 확인
- 위젯 설정 변경 후 실제 위젯에 반영되는지 수동 확인

## 10. 범위 밖 (이번에 안 만드는 것)

- 여러 기기 간 동기화, 클라우드 백업
- 계정 로그인/회원가입
- 데이터 내보내기/가져오기 (파일 백업), 필요 시 추후 별도 논의
