# 스티치 디자인 반영 계획

작성일: 2026-09-25
원본: `docs/design/stitch/` (DESIGN.md = 디자인 규칙, 각 폴더 code.html = 화면 HTML, screen.png = 화면 이미지)

## 결정 사항 (사용자 확정)

**만든다**
- 스티치 디자인의 색, 둥근 정도, 카드 스타일, 근무 8색, 하단 탭, 패턴 칩 연결(→), 위젯 배지 스타일
- 위젯 안 새로고침(↻), 설정(⚙) 버튼
- 위젯 설정 화면 상단 실시간 미리보기

**만들지 않는다 (디자인에 있어도 뺀다)**
- 근무 시간 표시 (07:00~15:30 등)
- 패턴 수정/순서 드래그/현재 적용 중·보관됨 배지/적용하기 버튼
- "다음 근무 D-1" 위젯, 알람/교대 바로가기 버튼
- 상단 알림 종, 프로필 아이콘
- 영어 화면 제목 (전부 한글로: 달력 / 근무 종류 / 근무 패턴 / 위젯 안내 / 위젯 설정)
- 위젯 안내 화면은 3개 변형 중 `widgets-guide`(4번) 기준으로 1개만
- Inter 폰트 (기본 폰트 유지)
- 배경 색 선택은 화이트/블랙 2개가 아니라 기존처럼 팔레트 여러 개 유지 (단, 흰 배경에서도 글자가 보이게 글자색을 배경 밝기에 맞춰 자동 결정)

**디자인이 없는 화면 (DESIGN.md의 Components 규칙으로 직접 구성)**
- 달력(홈), 근무 종류, 날짜 편집 시트, 월 이동 팝업, 각종 다이얼로그

## 기능 유지 원칙

기능/동작은 바꾸지 않는다. 지금 동작하는 것(패턴 자동 반복, 오버라이드, 메모 자동저장, 월 이동 팝업/스와이프, 근무종류 수정, 삭제 확인 등)은 그대로 두고 겉모습만 바꾼다. 단위 테스트 19개는 계속 통과해야 한다.

## 디자인 토큰 (DESIGN.md 요약)

- 메인: primary #1E3A8A (남색), 배경 #F8FAFC, 카드 #FFFFFF + 1px 테두리 #E2E8F0, 글자 #0B1C30
- 근무 8색: 주간 #2563EB, 오후 #F59E0B, 야간 #7C3AED, 휴무 #64748B, 당직 #E11D48, 연차 #10B981, 대기 #06B6D4, 교육 #EC4899 (근무종류 추가 시 색 선택 팔레트를 이 8색으로 교체)
- 달력: 일요일 #DC2626, 토요일 #2563EB, 오늘 배경 #EFF6FF + 링 #3B82F6, 메모 점 #F59E0B, 다른 달 날짜 #94A3B8
- 모양: 기본 8dp, 카드 16dp, 알약(배지/칩) 완전 둥글게, 바텀시트 위쪽 20dp, 위젯 16~24dp
- 글자 크기: 날짜 14, 근무 태그 10.5 굵게, 라벨 12 굵게, 제목 18~22 굵게

## 위젯(Glance) 제약

그림자, 블러, 그라데이션은 못 쓴다. 가능한 것: 둥근 모서리(cornerRadius), 색 배경, 알약 모양 배지(배경색 + 둥근 모서리), 이미지 아이콘(벡터 drawable), 클릭 동작. 정확한 API는 추측하지 말고 실제 라이브러리(javap)로 확인한다.
