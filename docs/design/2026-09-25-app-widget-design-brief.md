# 교대캘린더 디자인 브리프 (Stitch 작업용)

작성일: 2026-09-25

## 이 문서의 목적

지금까지 만든 앱은 기능은 다 동작하지만 디자인은 기본 스타일 그대로입니다. 이 문서는 "지금 이 화면/위젯에 어떤 정보와 기능이 들어있는가"를 정리한 것입니다.

Google Stitch 같은 도구로 새 디자인을 만드실 때, 여기 적힌 항목(정보, 버튼, 상호작용)은 그대로 유지하시고, 색상·폰트·아이콘·배치·여백 같은 건 전부 자유롭게 새로 디자인하시면 됩니다. 즉 이 문서는 "디자인 지침"이 아니라 "기능 체크리스트"입니다.

디자인이 나오면 화면 캡처(PNG)나 Stitch 결과물 링크로 주시면, 그걸 보고 실제 코드(Jetpack Compose, Jetpack Glance)에 반영하겠습니다.

---

## 공통 데이터 개념 (화면 전체에서 반복 등장)

- **근무 종류**: 이름 + 색상 (예: 주간=파랑, 야간=보라, 휴무=회색). 개수 제한 없이 자유롭게 추가
- **근무 패턴**: 근무 종류를 순서대로 나열한 것 + 시작일. 시작일부터 그 순서가 무한 반복됨
- **날짜별 오버라이드**: 특정 하루만 패턴과 다르게 수동으로 바꾼 것
- **메모**: 날짜별 텍스트 한 줄(또는 여러 줄)

## 앱 화면 (본 앱, 하단 탭 4개)

### 1. 달력 (홈 화면, 기본 탭)

**상단**
- 이전 달 버튼(◀) / 연월 텍스트(예: "2026년 10월") / 다음 달 버튼(▶)
- 연월 텍스트를 탭하면 **월 이동 팝업**이 뜸: 연도 좌우 스텝퍼 + 1~12월 버튼 그리드(선택한 달이 강조 표시됨) + "취소"/"이동" 버튼 2개. "이동"을 눌러야 실제로 달이 바뀌고, "취소"는 아무 변화 없이 닫힘
- 달력 영역을 손가락으로 좌우로 스와이프해도 이전/다음 달로 이동 가능

**요일 행**: 일~토 (일요일 빨강, 토요일 파랑, 평일 회색). 설정에서 월요일 시작으로 바꿀 수 있음(추후 반영 예정 — 현재는 이 화면엔 없고 위젯 설정에만 있음)

**월간 달력 그리드** (한 달 전체, 최대 6주)
- 각 날짜 칸: 날짜 숫자, 근무 이름(근무 색으로 표시), 메모가 있으면 작은 노란 점
- 오늘 날짜는 배경색으로 강조 + 굵은 글씨
- 근무 종류가 나중에 삭제된 날짜는 회색 "삭제됨" 텍스트로 표시(과거 기록은 남지만 무슨 근무였는지는 더 이상 알 수 없음을 의미)
- 날짜를 탭하면 아래에서 시트(패널)가 올라옴

**날짜 편집 시트** (날짜 탭 시)
- 선택한 날짜 표시 (예: "2026년 10월 15일")
- 근무 종류 칩들이 색깔별로 나열됨. 탭하면 **즉시** 그 날의 근무로 바뀜(별도 저장 버튼 없음)
- "이 날짜를 패턴 기본값으로 되돌리기" 버튼 (수동으로 바꾼 걸 취소하고 자동 패턴값으로 복귀)
- 메모 입력창 + "저장" 버튼. 저장 버튼을 안 눌러도 시트를 닫으면(바깥 탭, 아래로 스와이프) 자동 저장됨

### 2. 근무 종류 관리

- 등록된 근무 종류 목록: 색상 원 + 이름 + 삭제 버튼
- 목록의 행을 탭하거나 연필(수정) 아이콘을 누르면 **수정 팝업**이 뜸: 기존 이름/색이 미리 채워진 채로 수정 가능
- 화면 우하단 + 버튼 → **추가 팝업**: 이름 입력창 + 색상 선택(미리 정해진 8가지 색 중 하나, 고른 색에는 테두리 표시)
- 삭제 버튼을 누르면 확인 팝업이 뜸("이미 등록된 패턴/날짜에서는 '삭제됨'으로 표시됩니다")

### 3. 근무 패턴 관리

- 등록된 패턴 목록: 패턴 이름, 시작일, 근무 순서(색깔 칩들을 순서대로 나열)
- + 버튼 → **추가 팝업**: 패턴 이름 입력, 시작일(달력에서 날짜 선택), 근무 종류들을 순서대로 탭해서 쌓기(같은 근무를 연달아 여러 번 탭해도 됨), "현재 순서: 주간 → 주간 → 야간 → 휴무" 같은 미리보기 텍스트, "순서 초기화" 버튼
- 저장 버튼은 이름이 있고 순서가 하나라도 있어야 활성화됨
- 삭제 버튼 → 확인 팝업

### 4. 위젯 추가 안내

- 홈 화면에 위젯을 어떻게 추가하는지 안내하는 텍스트
- 4가지 위젯 종류와 크기를 텍스트 목록으로 나열 (현재는 그림 미리보기가 없고 텍스트 설명만 있음 — 여기에 실제 위젯 모양 미리보기를 넣으면 훨씬 좋아질 부분)

## 위젯 4종 (홈 화면에 직접 배치)

**공통 사항**
- 같은 종류를 여러 개 놓아도 각각 독립적으로 설정 가능
- 위젯을 처음 놓을 때(또는 길게 눌러 설정 재진입 시) 아래 항목을 조절하는 설정 화면이 뜸:
  - 배경색 (미리 정해진 6가지 색 중 선택)
  - 배경 투명도 (20%~100%)
  - 날짜/요일 글자 크기, 근무 이름 글자 크기, 메모 글자 크기 (각각 0.7배~1.6배)
  - 음력 표시 여부 (하루위젯/일주일위젯에만 있는 옵션)
  - 월요일부터 시작 여부

### 하루위젯
- 기본 크기 110×110dp(안드로이드 2×2칸), 최소 40×40dp까지 줄일 수 있음
- 내용: 오늘 날짜+요일, 근무 이름(크게), 메모(있으면 작게), 음력 날짜(켜져 있으면)
- 위젯을 탭하면 메모 입력 팝업이 뜸

### 일주일위젯
- 기본 크기 250×110dp(4×2칸), 가로 최소 180dp·세로 최소 40dp까지 줄일 수 있음
- 내용: 이번 주 7일이 가로로 나열. 각 칸에 요일/날짜/근무이름/근무색 밑줄/메모 앞 2글자/음력(켜져있으면)
- 칸을 탭하면 그 날짜의 메모 입력 팝업

### 작은한달위젯
- 기본 크기 180×140dp(3×2칸), 최소 110×130dp까지 줄일 수 있음
- 내용: 요일 행 + 한 달 전체 그리드. 칸이 작아서 근무 이름 텍스트는 생략하고 근무 색 밑줄만 표시
- 이전/다음 달 이동 없음 (항상 이번 달만 표시)
- 칸을 탭하면 메모 입력 팝업

### 한달위젯
- 기본 크기 250×250dp(4×4칸), 최소 180×220dp까지 줄일 수 있음
- 상단에 ◀ 연월 ▶ (위젯 안에서 직접 탭해서 이전/다음 달 이동, 팝업 없이 바로 이동)
- 요일 행 + 한 달 전체 그리드. 근무 이름 + 근무색 밑줄 + 메모 표시(작은 점)까지 다 나옴
- 칸을 탭하면 메모 입력 팝업

## 현재 알려진 제약 (참고용, 디자인과 무관)

- 위젯에 근무 패턴이 아직 하나도 없으면 그냥 빈 칸("근무 없음")만 나오고, "패턴을 먼저 등록해주세요" 같은 안내나 앱으로 이동하는 버튼은 없음
- 위젯 칸을 탭하면 항상 메모 입력창만 뜸 (근무 자체를 바꾸는 건 본 앱에서만 가능, 위젯에서는 불가)
- 위젯 추가 안내 화면에 실제 위젯 모양 그림이 없음 (지금은 앱 아이콘을 임시로 재사용 중)
- 근무 종류 색상은 미리 정해진 8가지, 위젯 배경색은 미리 정해진 6가지 중에서만 선택 가능 (색상 휠 등 자유 선택 아님)
- 완전 오프라인 앱이라 클라우드 동기화, 여러 기기 간 공유는 없음

## 화면 크기 참고 (안드로이드 위젯 기준)

안드로이드 홈화면 위젯은 "칸(cell)" 단위로 크기를 잡는데, 1칸 ≈ 70dp입니다.
- 하루위젯: 2×2칸 ≈ 110×110dp
- 일주일위젯: 4×2칸 ≈ 250×110dp
- 작은한달위젯: 3×2칸 ≈ 180×140dp
- 한달위젯: 4×4칸 ≈ 250×250dp

(dp는 "화면 밀도에 상관없이 일정한 크기로 보이는 단위"라고 생각하시면 됩니다. Stitch에서 픽셀 기준으로 작업하신다면 대략 1dp ≈ 화면 배율에 따라 다르지만, 위 비율(가로세로 비)만 맞춰주셔도 충분합니다.)

---

## Stitch로 작업하실 때 팁

- 화면별로 나눠서 만드시면 좋습니다: 달력, 근무종류 관리, 근무패턴 관리, 위젯 추가 안내, 그리고 위젯 4종(하루/일주일/작은한달/한달), 위젯 설정 화면
- 다크/라이트 모드 둘 다 고려하시면 좋지만, 필수는 아닙니다 (지금은 위젯은 어두운 배경, 앱은 기본 밝은 배경입니다)
- 위 "알려진 제약" 항목 중에 이번 디자인 작업에서 같이 개선하고 싶은 게 있으면(예: 패턴 미등록 안내, 위젯 미리보기 이미지) 그것도 화면에 포함해서 만들어 주시면 그대로 구현하겠습니다
